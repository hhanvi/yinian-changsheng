# 青崖山视觉与成长改版

用户选择按推荐方向直接实施，具体设计由实现者决定。

保留原生 HTML/CSS/JavaScript、SVG 可交互舆图和宗门经营循环；兼容 v3 及既有 v2 迁移，不改存档主键，不发布远端。

视觉以原创青绿山水插画为主景，石青 #285f69、松绿 #214f43、云白 #f0f4ec、淡金 #b49b60。宋体用于山门名与标题，微软雅黑用于操作及数字。开场以山水、题字和清晰行动为核心；游戏内用山门横卷连接可交互地图、成长目标和宗门状态。原始 SVG 建筑保留，并增加立体地台、稳定的地形纹理、云雾与飞鸟。桌面左景右事，手机上下排列，保持夜色与减少动态偏好。

玩法增加七章宗门长卷：初燃炉火、安居立业、弟子出山、丹书传道、守山立威、名动九州、一念长生。每章有可见条件、奖励、去向，依次领取，每章只领一次；已经达标的旧档可正常领取。另有按游戏内季节轮换的四时委托，明确交付成本和回报，每季一次，资源不足不扣费。

考虑仅换背景、重写引擎、沿用引擎补成长三种方式。选第三种，因为现有生产、历练及存档已经完整；视觉和内容可独立增强，不需要迁移平台。Astryx 可供设计参考，现有零构建离线游戏不适合引入框架模板与运行依赖，此处保留原生界面。

验收：原测试全部通过；奖励不可重复领取、章节不可越级、旧档可恢复、四时跨年不会串账、委托成本原子结算；桌面与手机、宣纸与夜色、地图交互和现有操作可用。新增插画随项目保存。
